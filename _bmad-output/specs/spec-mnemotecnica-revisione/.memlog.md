- (decision) G8 (DECIDED): the mnemonic is shown ONLY in review, after the attempt is submitted; never during the simulation. Reason: the simulation measures active recall; a mnemonic or right/wrong feedback mid-test would falsify the measure and the 1st-vs-2nd attempt comparison on the same test.
- (note) Why: mnemonics are the product differentiator (text or scene-to-imagine, tone may be ironic/bold); review of errors is where they are delivered, and it must lead into the 2nd attempt on the same test, the key product lever.
- (capability) CAP-1 Simulation shows no mnemonic and no correctness. Intent: during an in-progress simulation the candidate sees only question, options, timer, progress. Success: no mnemonic and no correct/incorrect signal appears anywhere in the simulation UI.
- (capability) CAP-2 Server-side withholding. Intent: the server never discloses mnemonic or correct answer for questions of an attempt not yet submitted. Success: for an in-progress attempt no API response contains mnemonic content or the correct answer, verified in the browser Network tab.
- (capability) CAP-3 Published-only mnemonic. Intent: review exposes only the mnemonic in state pubblicata, at most one per question. Success: mnemonics in draft, in-review or archived state never appear in any review response or screen.
- (capability) CAP-5 Per-question review content. Intent: for each reviewed question the candidate sees what they answered, what was correct, and the mnemonic. Success: category chip, question text, given answer marked wrong, correct answer marked correct, ministerial-correction indicator when applicable, MnemoCard below the correct answer, one-tap feedback below the card.
- (capability) CAP-6 Mnemonic always visible in review. Intent: the published mnemonic is displayed without any extra interaction. Success: after submission every wrong question with a published mnemonic shows it with zero additional taps.
- (capability) CAP-9 Resume. Intent: leaving and re-entering (or refreshing) resumes the review at the last error seen. Success: refresh mid-review reopens the same error; position is non-critical state stored locally only.
- (capability) CAP-11 MnemoCard. Intent: one card component renders a mnemonic in two visual variants, testo and scena da immaginare. Success: scene variant carries a label such as Immagina: and a slightly different visual tone; bold/ironic copy does not read as a tone error against the rest of the UI; legible at 360px with 5-6 line mnemonics; AA contrast.
- (capability) CAP-13 Offline-tolerant vote. Intent: the vote is saved optimistically and synced later, like answers. Success: a vote cast offline reaches the server when the connection returns; the UI reflects the vote immediately.
- (capability) CAP-14 Anonymous free-tier parity. Intent: anonymous free users (100 free questions) get review, mnemonics and feedback exactly as premium users. Success: review, mnemonics and voting work end to end with no login.
- (constraint) Withholding is enforced by the server, not the UI: hiding fields client-side is not acceptable; data must be invisible in browser dev tools. Rules out shipping correct answers or mnemonics with the simulation payload and grading on the client.
- (constraint) Only state pubblicata is ever served; at most one published mnemonic per question.
- (constraint) Vote write is idempotent, keyed by (mnemonic, user-or-anonymous-id); storage feedback_mnemotecnica with mnemotecnica_id, utente_id OR id_anonimo, valore, creato_il.
- (constraint) Votes use the same optimistic save + sync queue mechanism as answers; must work offline and for anonymous users.
- (constraint) Review position is local-only state; no server persistence for it.
- (constraint) Paywall N is computed, never hand-written; the threshold of errors seen is configurable.
- (constraint) Visual: sticker outline, marked border, flat hard shadow (no blur); gold accent oklch(78% .14 85) identifies the mnemonic; title Fredoka, body Inter; palette primary oklch(74% .13 178), primary dark oklch(46% .09 205), correct oklch(65% .16 145), wrong oklch(62% .20 20), background oklch(97% .02 90), text oklch(22% .02 50).
